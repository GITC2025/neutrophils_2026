# SingleR cell type ID with ImmGen
- following their workflow, with use SingleR and celldex to ID neutrophils with ImmGen reference
- Live sorting is not perfect due to cells being sticky
- the main difference is we only focus on dataset 1 and 2 - healthy cells

```R
# to see all references available 
library(celldex)
surveyReferences()
```

- https://rstats.immgen.org/DataPage/
- we use  immgen  2024-02-26 - Mouse microarray exp - PubMed:18800157: GEO:GSE15907, GEO:GSE37448
- there are 2 main options here - main labels vs fine labels
- fine labels gives more granular cell type ID but may discard more cells, so we can compare
- in the Neutrotime paper - they stated 6 fine categories - these have been collapsed into 4 labels in the celldex immgen reference
- cells that have no distinct identifications are discarded, resulting in cells_after

## doublet removal and decontamination
- typically we run scDoubletfinder to detect doublets according to the doublet rate of the platform
- however. scdblfinder is much better at identifying heterotypic doublets rather than homotypic doublets (same cell type)
- considering we have subset to neutrophils only, following the original workflow, we choose a data driven approach by identifying inflections at the extreme quantiles
- since we have subset by fine labels to neutrophils, we do not run decontamination here, as it becomes more difficult to identify contamination where other cell types are absent
- instead, the decontamination tool might treat rare neutrophil subtypes as contamination and over correct the data
- any contamination outliers can be identified as outlier clusters in UMAP and removed later
