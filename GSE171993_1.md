# run PCA
- we run principal component analysis as the first dimension reduction step
- this shows the axis of greatest variance, starting from PC1 and ending at PC30
- we also correlate with biological and technical variables

<img width="5850" height="3480" alt="GSE171993_pca_diagnostics_3x2_10Aug_033142" src="https://github.com/user-attachments/assets/4dd01f8d-a11f-44b7-b2bc-09f6a23e6fc0" /> 
- as expected, PC1 and PC2 are defined by developmental stage
- PC1 separates iNP and imNP, while PC2 seps imNP from mNP
- these stages are strongly correlated with cell cycle, with a tendency towards G1 stage as the neutrophils mature
- interestingly, the 'technical' covariates are of biological significance, so we won't regress them out
- immature neutrophils iNPs seem to be much more transcriptionally active and diverse compared to more mature neutrophils
- perhaps this is the reason the original authors did not set a count ceiling
- still, it is best to do a count ceiling filter, as extremely high counts tend to be doublets and will contaminate downstream analysis, e.g. exaggerating log fold change results

# Pseudotime trajectory
## monocle 3 cluster cells
- we now run monocle 3 trajectory analysis
- first we let monocle 3 do its own clustering and partitioning, at various resolutions
- default resolution is self-optimised to the dataset
- based on monocle's own clustering, it will build trajectories
- the default resolution looks good, but we know that this dataset is one cell lineage and therefore should be one partition
- the partition division happens due to the sparse number of cells in the center, integrating more datasets would likely fill up this gap
- since monocle can only build trajectories within each partition, we can override the partition divide and let monocle treat the entire UMAP as one partition
- the high resolution is also useful for finer differentiation
